# Character progression questions

> **Brainstorm — non-canonical.** This document explores unresolved questions.
> Accepted intent lives in [`design/progression.md`](../design/progression.md).

## XP requirements and level growth

- What shape should XP-to-next-level follow within and across the approximate
  100-level cycle bands?
- Should cycle transitions change the curve, or should one continuous curve
  span all four cycles?
- Which stats, if any, grow per level? Should growth be fixed, selected,
  equipment-mediated, or nonlinear?
- How much baseline power should separate the beginning and end of one cycle?
- How do approximate cycle bands map to actual encounter difficulty without
  equating character level to tower floor?

No current formula, including `TrackXP`'s curve and max-HP gain, is selected by
this brainstorm.

## XP distribution

- Is encounter XP divided among active survivors, granted in full to all party
  members, or weighted by another participation rule?
- Do dead members receive XP? What about members who entered but did not act?
- Do inactive parties receive any account-level catch-up or passive progress?
- Should shared account raids distribute character XP differently from normal
  encounters?

## Recruitment and catch-up

- At what level does a newly recruited character enter?
- Should catch-up use bonus XP, accelerated requirements, shared training,
  equipment access, or naturally available high-value encounters?
- How can catch-up preserve the value of developing a recruit without forcing
  obsolete-content farming?
- Should later parties have different catch-up support while retaining the same
  classless character foundation?

## Evaluation questions

- How many meaningful encounters should a level normally represent?
- What range of underlevel advancement should skilled play support?
- What amount of modest overleveling feels useful without replacing gear,
  skills, composition, or biome detours?
- Which measurements should regression experiments collect before any curve is
  proposed for approval?
